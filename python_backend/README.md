# InstaIdea AI - Instagram Content Strategist AI Agent
## دستیار هوشمند تولید ایده محتوای روزانه اینستاگرام با Python و Gemini API

این پروژه یک **ایجنت هوش مصنوعی اختصاصی** برای تولید روزانه ایده‌های محتوای اینستاگرام (Reel، Story، Carousel، Post) است که به طور خودکار اطلاعات پیج شما را تحلیل کرده و در ساعتی که تعیین می‌کنید، دقیقاً یک سناریوی کامل، هوک، کپشن، هشتگ و راهنمای ساخت را تحویل می‌دهد.

---

### 🌟 ویژگی‌های کلیدی
- **هوش مصنوعی استراتژیست با Gemini 3.8 Flash**: نقش Content Strategist حرفه‌ای با تحلیل لحن، پرسونای مخاطب و اهداف پیج.
- **جلوگیری از ایده‌های تکراری (Deduplication)**: ایجنت قبل از تولید هر ایده، تاریخچه ۲۰ ایده گذشته پیج را بررسی می‌کند تا از تکرار زاویه دید، هوک یا ساختار جلوگیری کند.
- **۱۴ بخش جامع برای هر ایده**:
  1. عنوان ایده
  2. نوع محتوا (Reel، Story، Carousel، Post، Live)
  3. هدف محتوا (افزایش فالوور، تعامل، فروش، برندینگ، آموزش، جذب مشتری)
  4. جمله شروع میخکوب‌کننده (Hook ۳ ثانیه اول)
  5. توضیح کامل ایده
  6. سناریوی پیشنهادی ثانیه‌ای
  7. متن دقیق کلامی برای ویدیو / اسلایدها
  8. کپشن آماده با ایموجی و ساختار
  9. دعوت به اقدام (Call To Action)
  10. پیشنهاد بصری (زاویه دوربین، نورپردازی، قاب)
  11. هشتگ‌های دسته‌بندی‌شده
  12. دلیل استراتژیک تناسب با این پیج
  13. میزان سختی اجرا (آسان، متوسط، پیشرفته)
  14. زمان تخمینی مورد نیاز برای ساخت
- **زمان‌بندی روزانه (Scheduler)**: اجرای خودکار در ساعتی که مشخص می‌کنید (مثلاً هر روز ساعت ۱۱:۰۰ یا ۱۸:۳۰).
- **اتصال به تلگرام و وب‌هوک**: امکان دریافت ایده مستقیماً روی ربات تلگرام شخصی یا اتوماسیون با Zapier / Make.
- **پایگاه داده مستقل SQLite**: ذخیره دائمی تاریخچه ایده‌ها، پروفایل پیج و لاگ‌های اجرا.

### 🚀 نحوه نصب و راه‌اندازی (گام به گام)

#### ۱. پیش‌نیازها
- پایتون نسخه ۳.۹ به بالا (`python3 --version`)
- کلید دسترسی Gemini API از [Google AI Studio](https://aistudio.google.com/)

#### ۲. نصب وابستگی‌های پایتون
در پوشه پروژه دستور زیر را اجرا کنید:
```bash
cd python_backend
pip install -r requirements.txt
```

#### ۳. تنظیم متغیرهای محیطی (.env)
یک فایل به نام `.env` در ریشه پروژه ایجاد کرده و کلید خود را قرار دهید:
```env
GEMINI_API_KEY="AIzaSy..."
DATABASE_PATH="instagram_agent.db"
API_HOST="0.0.0.0"
API_PORT=8000

# در صورت تمایل به ارسال اعلان تلگرام:
TELEGRAM_BOT_TOKEN="123456789:ABCdef..."
TELEGRAM_CHAT_ID="987654321"
```

#### ۴. اجرای ایجنت از طریق خط فرمان (CLI)
برای تست سریع و تولید یک ایده در ترمینال:
```bash
python cli.py generate
```

مشاهده تاریخچه ایده‌ها:
```bash
python cli.py history
```

#### ۵. اجرای سرور API پایتون (FastAPI)
```bash
python -m uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```
سپس مستندات Swagger در آدرس زیر در دسترس خواهد بود:
`http://localhost:8000/docs`

#### ۶. اجرای زمان‌بند روزانه (Scheduler Background Daemon)
برای اجرای مداوم زمان‌بند به صورت پس‌زمینه (مثلاً روی سرور لینوکس یا سیستم محلی):
```bash
python scheduler.py
```
یا با `nohup` در پس‌زمینه لینوکس:
```bash
nohup python scheduler.py > scheduler.log 2>&1 &
```
یا با استفاده از `systemd` در سرورهای ابری.
